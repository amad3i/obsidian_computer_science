## How to use

1. **Open this folder as a vault** in Obsidian: `File → Open folder as vault → C:\Users\N0ll\Desktop\obs`
2. Open the **Graph View** (Ctrl/Cmd+G) for the full map — start from `[[00-HOME]]`.
3. Navigate by **Maps of Content** below; each topic note links to related topics.
4. Filter the graph by `#core` (essential), `#intermediate`, `#advanced`, `#frontier`, or by domain tag.
5. Use `16-Courses` for systematic study paths (OSSU = full degree path, MIT OCW = real MIT courses).
