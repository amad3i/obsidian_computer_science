# Parametric animation

Parametric animation is an animation technique used in video game graphics that combines two or more separate animations together to form a new composite animation. This new animation is constructed in real-time by the game engine rather than being stored in a separate file. Parametric animations can reduce artist workload during game development and provide a smoother appearance.
This technique was first used in an early version of the game Team Fortress 2.
