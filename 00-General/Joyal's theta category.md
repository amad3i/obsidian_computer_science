# Joyal's theta category

In mathematics, especially category theory, Joyal's theta category 
  
    
      
        Θ
      
    
    
  
 is an alternative to the simplex category 
  
    
      
        Δ
      
    
    
  
. It was introduced by André Joyal to give a definition of an ∞-category using 
  
    
      
        Θ
      
    
    
  
-sets  = presheaves on 
  
    
      
        Θ
      
    
    
  
 instead of simplicial sets = presheaves on 
  
    
      
        Δ
      
    
    
  
. Namely, in the definition of Boardman and Vogt (which is the standard definition today), an ∞-category is defined as a simplicial set satisfying the weak Kan condition. In a similar way, Joyal proposed to define an ∞-category as a 
  
    
      
        Θ
      
    
    
  
-set satisfying the weak Kan condition.
In practice, the category 
  
    
      
        Θ
      
    
    
  
 is often used to define (∞, n)-categories.
