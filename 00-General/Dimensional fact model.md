# Dimensional fact model

The dimensional fact model (DFM) is a graphical notation and conceptual framework used in data warehousing to visually design a dimensional model. It maps out core business metrics (facts) and the analytical structures used to evaluate them (dimensions) before any physical database architecture is built. Because it relies on an intuitive visual shorthand rather than database schemas, both technical developers and non-technical business stakeholders can use it to rapidly establish a shared conceptual model early in a project.
Formally, DFM is a specialized graphical formalism specifically devised to support the conceptual modeling phase of a data warehouse life-cycle. A brief collaborative session is typically sufficient to create a clear and exhaustive tree-structured representation of multidimensional concepts (e.g., attributes, measures, and hierarchies) independent of the underlying physical architecture.
