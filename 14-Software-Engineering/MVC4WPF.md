# MVC4WPF

MVC4WPF for computer software is an open-source, extensible, automated code pattern developed at Information Control Corporation for Windows Presentation Foundation (WPF) development based on the Model–View–Controller (MVC) and Presentation–Abstraction–Control (PAC) patterns. It was released to the general public as an open source project on July 23, 2009. It depends on Microsoft's .NET Framework 3.5 and Visual Studio 2008 for functionality. The MVC4WPF source code for the 0.9 beta is available for download on CodePlex.
