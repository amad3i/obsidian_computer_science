# Forward Deployed Engineer

A forward-deployed engineer (FDE), also called a forward-deployed software engineer (FDSE), is a customer-facing software engineer who develops and deploys software within or alongside a client organization's operational environment. The role combines software development and system integration with direct collaboration with customer personnel and end users.
Responsibilities vary between employers, but may include requirements analysis, software development, data integration, application design, testing, deployment, and adapting software platforms to an organization's data, workflows, and technical infrastructure. Some forward-deployed engineers remain involved throughout an implementation, from identifying an operational problem to developing and deploying a production system.
