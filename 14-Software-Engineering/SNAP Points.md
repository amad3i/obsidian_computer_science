# SNAP Points

SNAP is the acronym for "Software Non-functional Assessment Process," a measurement of the size of non-functional software.   The SNAP sizing method complements ISO/IEC 20926:2009, which defines a method for the sizing of functional software. SNAP is a product of the International Function Point Users Group (IFPUG), and is sized using the “Software Non-functional Assessment Process (SNAP) Assessment Practices Manual” (APM) now in version 2.4. Reference “IEEE 2430-2019-IEEE Trial-Use Standard for Non-Functional Sizing Measurements,” published October 19, 2019 ().  Also reference ISO standard “Software engineering — Trial use standard for software non-functional sizing measurements,” (https://www.iso.org/standard/81913.html), published October 2021.  More information about SNAP can be found by going to YouTube and searching for "IFPUG SNAP;" which will provide a series of videos overviewing the SNAP methodology.
