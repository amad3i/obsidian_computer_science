# Disparity filter algorithm of weighted network

Disparity filter is a network reduction algorithm (a.k.a. graph sparsification algorithm

) to extract the backbone structure of undirected weighted network. Many real world networks such as citation networks, food web, airport networks display heavy tailed statistical distribution of nodes' weight and strength. Disparity filter can sufficiently reduce the network without destroying the multi-scale nature of the network. The algorithm is developed by M. Ángeles Serrano, Marian Boguna and Alessandro Vespignani.
