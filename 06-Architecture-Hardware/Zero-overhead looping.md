# Zero-overhead looping

In computer architecture, zero-overhead looping is a hardware feature found in some processors that enables loops to execute without the performance cost of traditional loop control instructions. Instead of software managing loop iterations, the processor's hardware handles repetition automatically, saving clock cycle and improving efficiency. This technique is commonly employed in digital signal processor (DSPs) and certain complex instruction set computer (CISC) architectures.
