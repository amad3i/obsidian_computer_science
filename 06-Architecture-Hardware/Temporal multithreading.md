# Temporal multithreading

Temporal multithreading is one of the two main forms of multithreading that can be implemented on computer processor hardware, the other being simultaneous multithreading.  The distinguishing difference between the two forms is the maximum number of concurrent threads that can execute in any given pipeline stage in a given cycle.  In temporal multithreading the number is one, while in simultaneous multithreading the number is greater than one. Some authors use the term superthreading synonymously.
