# AMD XDNA

XDNA is a microarchitecture for deep learning processor developed by AMD. It is designed to handle Machine learning (ML)-related tasks, such as artificial intelligence (AI) software. It is based on Xilinx technology, which AMD acquired in 2022. XDNA-based silicon designs are incorporated into the company's Ryzen AI-branded processors where it supplements the Zen CPU and RDNA GPU on the same chip.
