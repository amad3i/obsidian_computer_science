# MSN Groups

MSN Groups was a website part of the MSN network that hosted online communities, and that contained Web pages, hosted images, and contained a message board. MSN Groups was shut down on February 21, 2009, as part of a migration of online applications and services to the Windows Live brand. Windows Live Groups, a part of the Windows Live branding, was never marketed as, or intended to be a replacement for, MSN Groups.
