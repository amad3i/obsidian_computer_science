# Biological network

A biological network is a method of representing systems as complex sets of binary interactions or relations between various biological entities. In general, networks or graphs are used to capture relationships between entities or objects. A network can be represented as an N×N matrix where N is the number of nodes, and whose entries tell you if two nodes share an edge. Typically, this matrix will have entries of 0 or 1 with 1 denoting an edge. We can optionally use a weighted graph by assigning a weight to each edge to show how relevant the connection between two nodes is.
