# Type inhabitation

In type theory, a branch of mathematical logic, in a given typed calculus, the type inhabitation problem for this calculus is the following problem: given a type 
  
    
      
        τ
      
    
    
  
 and a typing environment 
  
    
      
        Γ
      
    
    
  
, does there exist a 
  
    
      
        λ
      
    
    
  
-term M such that 
  
    
      
        Γ
        ⊢
        M
        :
        τ
      
    
    
  
? With an empty type environment, such an M is said to be an inhabitant of 
  
    
      
        τ
      
    
    
  
.
