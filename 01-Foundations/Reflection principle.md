# Reflection principle

In set theory, a branch of mathematics, a reflection principle says that it is possible to find sets that, with respect to any given property, resemble the class of all sets. There are several different forms of the reflection principle depending on exactly what is meant by "resemble". Weak forms of the reflection principle are theorems of Zermelo–Fraenkel set theory (

The name "reflection principle" comes from the fact that properties of the universe of all sets are "reflected" down to a smaller set.
