# Homomorphic equivalence

In graph theory, a branch of mathematics, two graphs G and H are called homomorphically equivalent if there exists a graph homomorphism 
  
    
      
        f
        :
        G
        →
        H
      
    
    
  
 and a graph homomorphism 
  
    
      
        g
        :
        H
        →
        G
      
    
    
  
. An example usage of this notion is that any two cores of a graph are homomorphically equivalent.
Homomorphic equivalence also comes up in the theory of databases. Given a database schema, two instances I and J on it are called homomorphically equivalent if there exists an instance homomorphism 
  
    
      
        f
        :
        I
        →
        J
      
    
    
  
 and an instance homomorphism 
  
    
      
        g
        :
        J
        →
        I
      
    
    
  
.
Deciding whether two graphs are homomorphically equivalent is NP-complete.
