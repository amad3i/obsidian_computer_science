# Diagram (mathematical logic)

In model theory, a branch of mathematical logic, the diagram of a structure is the set of sentences with parameters from the structure that are true in the structure, denoted 
  
    
      
        D
        
          
            A
          
        
      
    
    
  
 or 
  
    
      
        
          Diag
        
        
          
            A
          
        
      
    
    
  
 for a structure 
  
    
      
        
          
            A
          
        
      
    
    
  
. Usually 'diagram' means the atomic diagram that contains only the atomic and negated atomics sentences which are true in the structure. We can also define the elementary diagram that contains all true sentences.    
Diagrams are a simple but powerful tool for proving useful properties of a theory, for example the amalgamation property and the joint embedding property, among others. The name 'diagram' was introduced by Abraham Robinson, the first model theorist to make systematic use of diagrams.
