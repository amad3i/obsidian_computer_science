# Volumetric capture

Volumetric record or volumetric video is a technique that records a three-dimensional space, such as a location or performance. This type of volumography acquires data that can be visualized as 2D projections as well as using 3D displays and VR headset. Consumer-facing formats are numerous and the required motion capture techniques lean on computer graphics, photogrammetry, and other computation-based methods. The viewer generally experiences the result in a real-time engine and has direct input in exploring the generated volume.
