# IceWarp Mail Server

IceWarp Mail Server is a business Email and Collaboration server developed by IceWarp Ltd. It features email with a custom domain, shared calendars, document editing, messaging and advanced tool for team collaboration. It can be run in the cloud or on a local server using either Windows or Linux, or together with another solution in a hybrid deployment. In 2006, it was known as Merak Mail Server.
It incorporates groupware capabilities over SyncML protocol, as well as SMTP, IMAP and POP and can be integrated with other modules, including those for groupware, antispam and antivirus.
IceWarp Mail is available in the mobile app. The solution is an alternative to global products offered by Microsoft and Google. IceWarp solution is available to purchase on numerous Marketplaces such as Hostinger, Vultr, Digital Ocean and SofwareOne. In 2026 product has AI funcionality.
