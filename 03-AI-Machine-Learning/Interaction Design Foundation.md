# Interaction Design Foundation

The Interaction Design Foundation (IxDF) is an educational organization. which produces open access educational materials
The programs are not accredited..
The Executive Board currently include Don Norman, Ken Friedman, Bill Buxton, Irene Au, Michael Arent, Daniel Rosenberg, Jonas Lowgren, and Olof Schybergson.
