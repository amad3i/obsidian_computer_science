# Hugging Face

Hugging Face, Inc., is an American company based in New York City that develops computation tools for building applications using machine learning.  Hugging Face's transformers library is built for natural language processing applications.  The Hugging Face platform allows users to share machine learning models and datasets and showcase their work.
