# Superblock (file system)

In computer file systems, a superblock is a critical metadata structure that contains information about the file system's layout, size, and status. It is used by the operating system to understand and manage the file system stored on a storage device. Without a valid superblock, the file system cannot be correctly mounted or interpreted. Usually multiple copies of the superblock are kept on the volume.
