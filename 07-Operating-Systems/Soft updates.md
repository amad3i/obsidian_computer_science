# Soft updates

Soft updates is an approach to maintaining file system metadata integrity in the event of a crash or power outage.  Soft updates work by tracking and enforcing dependencies among updates to file system metadata.  Soft updates are an alternative to the more commonly used approach of journaling file for systems.
