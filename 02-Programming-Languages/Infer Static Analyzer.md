# Infer Static Analyzer

Infer, sometimes referred to as "Facebook Infer",  is a static code analysis  tool developed by an engineering team at Facebook along with open-source contributors. It provides support for Java, C, C++, and Objective-C, and 
is deployed at Facebook in the analysis of its Android and iOS apps (including those for WhatsApp, Instagram, Messenger and the main Facebook app).
