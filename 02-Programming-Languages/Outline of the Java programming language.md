# Outline of the Java programming language

The following outline is provided as an overview of and topical guide to Java:
Java is a general-purpose, concurrent, object-oriented, class-based, strong, and statically typed programming language that is compiled to JVM bytecode for execution on a Java virtual machine (JVM), which allows "write once, run anywhere" programming. Java was designed by James Gosling and a team at Sun Microsystems in the early 1990s and was a core component of Sun's Java platform.
