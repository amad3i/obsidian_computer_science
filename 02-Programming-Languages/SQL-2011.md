# SQL:2011

SQL:2011 or ISO/IEC 9075:2011 (under the general title "Information technology – Database languages – SQL") is the seventh revision of the ISO (1987) and ANSI (1986) standard for the SQL database query language.  It was formally adopted in December 2011. The standard consists of 9 parts which are described in detail in SQL.
The next version is SQL:2016.
