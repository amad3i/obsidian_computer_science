# Cangjie (programming language)

Cangjie (Chinese: 仓颉; pinyin: cāngjié) is a high-level, statically typed, general-purpose, multi-paradigm, compiled imperative and declarative programming language developed by Huawei. It was first released on June 21, 2024, as part of developer beta recruitment, for HarmonyOS NEXT app development on the preview version of the HarmonyOS operating system. It is also referred to as CangjieLang or CJ, but its proper name is Cangjie.
