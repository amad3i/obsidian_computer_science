# IDEF4

IDEF4 (Integrated Definition for Object-Oriented Design) is an object-oriented design modeling language for the design of component-based client/server systems. It has been designed to support smooth transition from the application domain and requirements analysis models to the design and to actual source code generation. It specifies design objects with sufficient detail to enable source code generation.
This method is part of the IDEF family of modeling languages in the field of systems and software engineering.
