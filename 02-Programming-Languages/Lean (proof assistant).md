# Lean (proof assistant)

Lean is a proof assistant and a functional programming language. It is based on the calculus of constructions with inductive types (specifically, the Calculus of Inductive Constructions), the foundational type theory originally developed with the Coq theorem prover, which was renamed to Rocq in 2024. It is a free and open-source software project hosted on GitHub. Development is currently supported by the nonprofit Lean Focused Research Organization (FRO).
