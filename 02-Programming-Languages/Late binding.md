# Late binding

Late binding is the act or mechanism of binding two software entities at runtime as opposed to early binding which occurs before the  program starts – such as  design or build times.
The implementation of late binding differs by context. 
The term dynamic binding is sometimes used for the same concept, but is more commonly refers to dynamic scope.
